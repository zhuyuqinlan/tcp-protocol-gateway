## tcp-protocol-gateway 项目开发完成

- 在 D:/zhuyuqin/dev/tcp-http 从零实现 Go TCP 多协议网关（零第三方依赖，纯标准库）。
- 模块：internal/config（内置 YAML 子集解析器）、internal/detector（Peek 嗅探）、internal/proxy（TCP 双向转发）、internal/minecraft（VarInt/Handshake/SLP 状态机）、internal/gateway（监听/并发控制/优雅退出）。
- 关键设计：HTTP 判定要求"方法+空格+可见 ASCII"（防 MC 长度 0x47='G' 误判）；TLS 用 0x16 0x03 ≤0x04 三字节判定（防 MC 握手长度 22=0x16 误判）；Peek 窗口 16 字节（OPTIONS 占满 8 字节问题）。
- 踩坑记录：嗅探只 Peek 不消费，Minecraft 分发前必须从 Reader 正式读取握手包，否则状态机会把握手包当 Status Request。
- 验证：go vet / go test 全过（含 10 类场景集成测试）；二进制冒烟（HTTP GET/POST、SLP Status/Pong、Login Disconnect、未知协议关闭）真实环境跑通。
- 环境限制：Windows 本机无 gcc，`go test -race` 无法执行（需 CGO），已在 README 说明。
