- 在 D:/zhuyuqin/dev/tcp-http 从零实现 Go TCP 多协议网关（零第三方依赖，纯标准库）。
- 模块：internal/config（内置 YAML 子集解析器）、internal/detector（Peek 嗅探）、internal/proxy（TCP 双向转发）、internal/minecraft（VarInt/Handshake/SLP 状态机）、internal/gateway（监听/并发控制/优雅退出）。
- 关键设计：HTTP 判定要求"方法+空格+可见 ASCII"（防 MC 长度 0x47='G' 误判）；TLS 用 0x16 0x03 ≤0x04 三字节判定（防 MC 握手长度 22=0x16 误判）；Peek 窗口 16 字节（OPTIONS 占满 8 字节问题）。
- 踩坑记录：嗅探只 Peek 不消费，Minecraft 分发前必须从 Reader 正式读取握手包，否则状态机会把握手包当 Status Request。
- 验证：go vet / go test 全过（含 10 类场景集成测试）；二进制冒烟（HTTP GET/POST、SLP Status/Pong、Login Disconnect、未知协议关闭）真实环境跑通。

## HTTP 前缀过滤功能

- 用户选择语义：仅放行匹配前缀的请求。新增配置 `http.prefix`（空=全部放行，必须以 / 开头），不匹配返回 404 且不触碰后端。
- 实现：proxy.Handle 在拨号后端前 Peek 请求行（不消费数据）匹配 request-target；拒绝路径返回固定 404 响应。
- 重要语义：网关是透明 TCP 代理，keep-alive 长连接建立后是纯字节隧道，前缀过滤只约束每个 TCP 连接的第一个请求——已写入 README，测试用 DisableKeepAlives 验证。

## 多路由映射 + Minecraft 模拟回退

- 配置重构：移除 http.backend/prefix 单路由，新增 `routes` 段（HTTP 前缀映射仅主端口 + TCP/UDP 独立监听端口映射；键为前缀/监听地址，值为后端）。
- YAML 解析器修复：支持含冒号的引号键（`"0.0.0.0:30000": ...`），splitKeyValue 按闭合引号定位。
- 新增 internal/relay：UDP 数据报中继，按客户端地址会话、idle_timeout 回收。
- 未匹配 HTTP 前缀不再返回 404：回退到 Minecraft 模拟（按 MC 协议解析，非法包直接断开，与原版服务器一致）。
- 踩坑：TCP 路由最初用 ln.Addr().String() 反查后端映射失败（backend=""），改为 tcpRoute{listener,backend} 结构体直传；gofmt 需要在写大文件后重跑。
- 冒烟全过：HTTP 多路由、TCP 30000→9000 回显、UDP 30001→9001、SLP Status、未匹配 HTTP 无响应断开。



## 前缀剥离功能（strip_prefix）
- `routes.http` 条目支持两种写法：字符串=透明转发；对象 `{backend, strip_prefix}`=转发前剥掉命中前缀。
- 实现：proxy.Route/Match 新增 Strip 字段，Handle 在冲刷前重写首个请求行（剥完为空→`/`，不以/开头补/，查询串保留，形态异常保底原样转发）。
- 边界：只重写每个 TCP 连接的第一个请求（keep-alive 后续请求是纯隧道），已写入 README。
- 验证：单元/集成测试 + 真实二进制冒烟（/api/users→/users、/api→/、透明路由不剥离）全部通过。
